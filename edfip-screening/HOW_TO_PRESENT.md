# How to present this deck

This material is confidential. **Do not put it on Vercel, Netlify, Google Sites, or any public URL.**

## What to open

File: `edfip-screening/index.html`

1. Copy the `edfip-screening` folder to your laptop.
2. Open `index.html` in **Chrome**.
3. Press **F** for fullscreen (or F11).
4. In Zoom / Google Meet / Teams: **Share that Chrome window** (not the whole desktop if you will use notes).

Keys:

- Right arrow / Space / click right half of screen → next
- Left arrow / click left half → back
- **N** → speaker notes on this computer (do not share that if notes cover the slide; better: print `SPEAKER_NOTES.md` on a second screen or phone)
- **F** → fullscreen

Backup: `EDFIP_Screening_Dexta.pptx` — use if they ask you to email slides or if Chrome share is awkward.

To make a PDF: Chrome → Print → Save as PDF → layout Landscape.
